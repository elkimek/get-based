# CLI agent identification marks

Audited 2026-09-04. These assets identify compatible third-party software in
settings and chat. They do not represent a partnership, sponsorship, or
endorsement. getbased keeps each mark subordinate to its own identity, pairs it
with the full product name, preserves its aspect ratio, and does not use it as
getbased branding. Third-party names and marks remain their owners' property.

| UI agent | Asset source | Release rule |
|---|---|---|
| Codex CLI | Black Monoblossom from OpenAI's official `OpenAI-Logos-2025.zip` | Embedded unchanged for identification only, with built-in clear space on a quiet white tile. Do not recolor, distort, add effects, or present it as getbased branding. |
| Claude Agent | getbased's neutral terminal glyph | Anthropic permits “Claude Agent” in dropdowns but prohibits “Claude Code” and Claude Code-like visuals for integrations. No Anthropic or Claude logo is bundled. The adapter is hidden by default and may be exposed only for explicit Anthropic Console/API-billed self-hosting. |
| OpenCode | `packages/identity/mark.svg` from the official `anomalyco/opencode` repository | Original black, gray, and white mark. The repository is MIT licensed; the name and mark remain their owners' identifiers. getbased's product name does not incorporate “OpenCode.” |
| Hermes Agent | Official 32 px desktop application icon generated by the `NousResearch/hermes-agent` project | PNG bytes are embedded unchanged. The upstream repository is MIT licensed. Keep it paired with “Hermes Agent.” |
| Grok Build | getbased's neutral terminal glyph | SpaceXAI permits accurate referential naming but requires downloaded logo artwork to remain exactly as supplied. No SpaceXAI mark is bundled, so the compact UI cannot accidentally alter, crowd, or imply endorsement through it. |
| OpenClaw | `dist/control-ui/favicon.svg` bundled with the official `openclaw` package | Static settings copy preserves the official geometry, colors, proportions, and clear space; only decorative animation is omitted. The upstream package is MIT licensed. |

Primary sources reviewed:

- OpenAI Design Guidelines: https://openai.com/brand/
- Anthropic Agent SDK branding and authentication guidance: https://code.claude.com/docs/en/agent-sdk
- Anthropic legal and compliance guidance: https://code.claude.com/docs/en/legal-and-compliance
- OpenCode repository and MIT license: https://github.com/anomalyco/opencode
- Hermes Agent repository and MIT license: https://github.com/NousResearch/hermes-agent
- SpaceXAI Brand Guidelines: https://x.ai/legal/brand-guidelines
- Official Grok Build repository: https://github.com/xai-org/grok-build
- OpenClaw repository and MIT package metadata: https://github.com/openclaw/openclaw

The neutral Grok Build glyph is loaded on demand and then stored by the normal
same-origin runtime cache; it is not part of the first-install app shell.
